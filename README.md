# Huddl v27

Mobile-first Svelte 5 frontend for Huddl.

## v27 UI update
- Rebuilt event sport, skill-level, and visibility selectors as custom Huddl controls instead of native Android/browser selectors.
- Unified selector geometry, borders, spacing, pastel selected states, and offset shadows with the rest of the app.
- Sport selector uses a two-column touch-friendly grid.
- Skill-level selector uses five levels: Beginner, Amateur, Intermediate, Seasoned, Professional.
- Visibility selector uses the same custom list treatment as skill selection.
- Profile sport skill buttons accommodate all five skill levels.
